Jailbreak

Controls:
WASD or arrow keys - Move
Space - Dash
Mouse - Aim
Left mouse - Fire pistol
Hold right mouse - Bullet time
Release right mouse - Stop bullet time
Esc or Tab - Pause or resume
Menus - Click buttons
Main menu Controls - View the control reference
F1 - Toggle debug overlay

Debug overlay:
1 Toggle invincibility
2 Restore health
3/4 Increase/decrease speed
6 Skip level
7 Reload level
8 Toggle collision boxes
9 Freeze enemy AI

Level progression:
Each prison block treats clearing all enemies as the level goal.
When the room is secure, the next level loads automatically.
Triggered checkpoints let you resume from that checkpoint after dying.
Save and load use one progress file from the menus.

Saving:
Save/load keeps the current level, player health, player position, checkpoint position, dash charges, and bullet-time meter.
Space dashes with 3 charges. Killing an enemy refreshes dash charges.
